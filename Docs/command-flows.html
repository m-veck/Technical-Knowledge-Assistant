The flow

Each white box with tka in front is a command you type: click it to jump to its steps. Under a filter, a command that the part only reuses (through its code) stays half visible. Grey arrows show where data goes; green dashed arrows show a command that runs the code of another one. The purple labels are the outside services a box calls. The filter highlights one part here, in the file tree, the table and the command list.

Which file belongs to which part

The code in src/tka/ and the data it reads and writes. A file used by more than one part shows every part. cli.py and config.py serve all of them.

What touches what

One row per file or service, one column per command. R reads, W writes, R + W both, call calls the service. Empty: never touches it.

The guardrail in one row: the queries dataset is read by split (ids only) and by the three evaluation runs. index, search and ask never read it, so nothing from it can reach the index, the prompt or an answer.
